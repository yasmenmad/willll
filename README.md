A playful interactive web micro-application demonstrating dynamic DOM event handling, coordinates calculation, and button repulsion physics in vanilla JavaScript.

---

## How It Works
- Hovering or attempting to click the **"No"** button recalculates viewport bounds and translates the element randomly across the window to prevent selection.
- Clicking **"Yes"** triggers transition to a celebration confirmation view with custom typography and animations.

---

## Quick Run
Open `index.html` directly in any web browser.
